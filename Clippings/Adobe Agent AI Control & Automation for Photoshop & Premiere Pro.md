This proof-of-concept project empowers Large Language Models (LLMs) like Claude to interact with and control Adobe Photoshop and Premiere Pro. It establishes a robust communication bridge through the MCP protocol, comprising an MCP server, a Node.js command proxy, and dedicated Adobe application plugins. This innovative setup allows users to issue natural language commands to their Adobe applications, automating complex tasks, generating content, and even providing step-by-step guidance, effectively transforming LLMs into powerful creative assistants.

## Key Features

01Supports Claude Desktop and other MCP protocol-compatible AI applications

02150 GitHub stars

03Integrates Large Language Models with Adobe Photoshop and Premiere Pro

04Enables conversational control and automation of creative tasks

05Utilizes a modular architecture with an MCP server, Node proxy, and UXP plugins

06Allows AI to query information from Photoshop for self-correction

## Use Cases

01Automate creative tasks like generating templates or double exposures in Adobe apps

02Generate personalized Photoshop tutorials with example files and instructions

03Provide conversational, step-by-step instructions to Claude for Photoshop tasks
