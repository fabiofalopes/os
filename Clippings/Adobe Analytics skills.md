Skills are modular, reusable capabilities that let an AI agent carry out a specific Adobe Analytics task from a natural-language request. Each skill packages the instructions an agent needs to route your request to the right workflow — for example, monitoring KPIs, investigating top movers, analyzing funnels, comparing segments, or assembling an executive briefing — and runs on top of the [Adobe Analytics MCP server](https://developer.adobe.com/analytics-mcp/docs/aa/ "Adobe Analytics MCP server").

Adobe Analytics skills are published in the Adobe Skills repository, a central exchange for discovering, installing, and contributing Adobe product skills. Skills are grouped into a per-product plugin that you can add to supported AI clients such as Claude Code and Cursor. To browse the available Adobe Analytics skills, see installation steps, and review prerequisites, visit the plugin page on GitHub.
