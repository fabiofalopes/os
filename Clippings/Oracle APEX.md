## Introducing APEXlang: the Application Definition Language

APEX 26.1 introduces APEXlang, a declarative, human-readable application definition language for Oracle APEX applications.

APEXlang gives developers and AI agents a supported way to express application intent as structured metadata that can be reviewed, versioned, governed, and executed by APEX.

- Human-readable application definitions
- Version, review, and govern application intent
- A foundation for AI-assisted development

[Learn about APEXlang](https://oracle.com/apex/ai-application-generator)

Developers build and deploy applications knowing that data access, user management, and application behavior are managed within a consistent, enterprise-ready environment.

## Additional Enhancements in APEX 26.1

### App Builder

Enhancements across the development experience make Oracle APEX more efficient and intuitive, with features like infinite scroll for LOV and autocomplete fields, a refined Page Designer with improved search and context-rich diff views, and Builder Extension backlinks that enable seamless integration directly into Page Designer or Workflow Designer.

### Workflow

Expanded workflow capabilities include support for parallel flows, new APIs for greater extensibility and control, and built-in multi-tenancy awareness to better support complex, scalable application architectures.

### Universal Theme

Updates to Universal Theme introduce a refreshed Oracle-branded look and feel, enhanced accessibility, and Font APEX 2.5, along with modern development features like client-side partials, template directives, and improved autocomplete support for a faster, more flexible UI experience.

### Security

Security enhancements strengthen how applications connect and operate, with REST data source support for Dynamic OAuth scopes, signed assertions, and password flows, along with CSP improvements, stronger Fusion Extensions security, and new workspace-level SMTP controls for better governance and protection.

### Components

Component enhancements expand what you can build declaratively, with support for buttons and menus, new actions like Show Success and Error, and a built-in Wait Popup, alongside map region improvements including vector tile layer support and greater JavaScript control for richer, more interactive experiences.

### Translations

A new message-based translation model simplifies how applications are localized, making it easier to manage and update translations without the need for maintaining shadow applications.

## Support

Oracle APEX is a fully supported no-cost feature of the Oracle Database. Therefore, your Oracle Database maintenance agreement also covers support for Oracle APEX. Oracle's Lifetime Support policies maximize your investment protection and provide peace of mind knowing that we'll be there to support you.

Oracle APEX is generally supported for 18 months from release, with support provided for the current release and the two prior releases. Due to the May 2026 release date of APEX 26.1, the previous three releases received an extended support period.

## Pricing

**Free with Oracle Database**

Oracle APEX is included at no additional cost with all supported editions of the Oracle Database and the Oracle APEX AI Application Generator. There are no separate license fees for APEX.

**Enterprise Support  
**

Oracle APEX is fully supported by Oracle. With an active Oracle Database support contract, you receive enterprise-grade assistance covering the complete stack, including APEX, Oracle REST Data Services (ORDS), and Oracle Database.

**No Limits on Applications or Users**

There are no limits on the number of applications, developers, or end users. Organizations can build and deploy unlimited applications without per-user or per-app licensing fees.

**Full-Featured Platform**

All APEX functionality is available regardless of where it runs - on premises or in the cloud. There are no feature restrictions tied to deployment model.
