## Quick Start

### Prerequisites
1. **CDP API Keys** (free): https://cloud.coinbase.com
   - Create account → API Keys → Create new key pair
2. **OpenAI API Key**: https://platform.openai.com/api-keys

### Setup
```bash
cd alpha-scanner
cp .env.example .env
# Fill in your keys in .env
npm install
npm run scan  # Test a single scan
npm start     # Run continuous scanning
```

### First Steps ($0)
1. Run on Base Sepolia testnet (free)
2. Agent learns your network, tests actions
3. Move to Base mainnet (gas costs ~$0.01 per scan)
4. Start generating signals
5. Connect social platforms
6. Build audience → monetize

## What It Scans For

- **Whale wallets**: Track addresses with >$1M, alert on their moves
- **New listings**: Tokens just added to DEXs before they pump
- **Liquidity changes**: Sudden liquidity adds/withdrawals = signals
- **Yield opportunities**: Best APYs across lending protocols
- **Arbitrage**: Price differences between DEXs
- **NFT flips**: Undervalued listings in trending collections
