# Yield Optimizer Agent

Auto-moves funds to the highest APY across DeFi protocols. Never lets capital sit idle.

## Protocols Monitored
- Aave (lending/borrowing)
- Compound (lending)
- Morpho (optimized yield)
- Moonwell (lending)
- Hyperbolic (lending)
- Plus any new high-APY protocols

## Revenue
- Passive APY: 5-15% on deployed capital
- Auto-compounds weekly
- $1000 → $50-150/month passive

## Quick Start
```bash
cp .env.example .env
# Fill in keys
npm install
npm run check    # Check current best APYs
npm start        # Run continuous optimization
```
